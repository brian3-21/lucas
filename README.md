# Lucas

Personal finance tracker built with SvelteKit.

## Getting Started

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run check` - Run type checking

## Tech Stack

- SvelteKit + Svelte 5
- TypeScript
- Tailwind CSS
- Drizzle ORM
- PostgreSQL
